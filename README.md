# SIPL Language Toolkit

Інструментарій для навчальної мови програмування **SIPL** (SImple Programming Language) у межах курсового проєкту з дисципліни «Теорія програмування».

## Обраний набір завдань (10.0 балів)

 ID  Назва модуля  Бали   

 `CORE-01`  Формальна специфікація SIPL (Lark/EBNF) + позитивні/негативні   тести  0.5 

 `CORE-02`  Парсер та типізоване AST з позиціями у вихідному тексті (`SourceSpan`)  1.5 

 `CORE-03`  Інтерпретатор SIPL із контролем ліміту кроків та покриттям тестами $\ge 80\%$  2.0 

 `CORE-05`  CLI (`parse`, `check`, `run`) зі стабільною JSON-схемою та кодами завершення  1.0 

 `CORE-06`  Незалежний Conformance Suite для верифікації реалізацій SIPL  1.0 

 `IDE-01`  VS Code extension: синтаксис `.sipl`, коментарі, сніпети  1.0 

 `IDE-02`  Інтеграція команд `Run SIPL` та `Check SIPL` з панеллю Diagnostics у VS Code  1.0 

 `REL-01`  CI пайплайн (lint, type-check, tests, build) у GitHub Actions  0.5 

 `REL-02`  Релізний цикл (SemVer, `CHANGELOG.md`, GitHub Releases)  0.5 

 `REL-03`  Пакування та публікація Python-пакета в PyPI  0.5 

 `REL-04`  Пакування та публікація `.vsix` артефакту VS Code extension  0.5
